An embeddable multimedia engine: shows are JSON documents of layers,
scenes and timelines, driven by a host's values and events.

- [cuelight](https://github.com/cuelight-org/cuelight): the engine and the show format
- [cuelight-editor](https://github.com/cuelight-org/cuelight-editor): an editor for shows, [in the browser](https://cuelight-org.github.io/cuelight-editor/)
- [cuelight-examples](https://github.com/cuelight-org/cuelight-examples): example shows, [playing live](https://cuelight-org.github.io/cuelight-examples/)
